# Telegram Project Bot

Красивый Telegram-бот на Python + aiogram 3 для проекта с меню:
- 💬 перейти в чат;
- ❤️ поддержать проект;
- 👨‍💼 связаться с куратором.

## Настройки

`BOT_TOKEN` — токен Telegram-бота.
`CHAT_URL` — ссылка на основной чат/группу.
`SUPPORT_URL` — ссылка на поддержку/донат.
`CURATOR_ID` — Telegram ID куратора, которому пересылаются сообщения.
`BOT_NAME` — название проекта.

Куратор получает сообщение пользователя с кнопкой «Ответить». После нажатия бот переводит куратора в режим ответа конкретному пользователю.

Для получения Telegram ID можно временно написать боту @userinfobot или использовать другой удобный способ.
